# Plans

This section is the home for implementation plans, migration sequences, capability backlogs, and historical decision records.

There are currently no active plan documents. Add a plan here only while work is proposed or in progress. When implementation is complete, move the durable behavior into **Architecture**, **Design**, **Reference**, or **Development**, and either archive or remove the obsolete plan.

A plan is not an API contract. Current code and the formal documentation sections remain authoritative.
